A workshop for your campaign

Edit the labeled fields in Player, Opponents or Campaign. Changes reviews all unsaved edits by category.

Save changes writes the opened file after review and creates a backup. Export a copy keeps the original editing session. Close the game before saving.

To restore a backup, open its .bak file and export it to ClassicSave.sav. Steam Cloud can replace local files during synchronization.

Advanced mode exposes IDs, asset paths and raw fields. These can break game relationships. Structural flags and collection sizes are read only. Editing a value does not guarantee that the game accepts every possible value.
